# 🌌 fract-ol

A graphical project developed as part of the **42 School curriculum**, focused on rendering and exploring mathematical fractals such as the **Mandelbrot** and **Julia** sets using a minimal graphics library.

---

## 📖 Overview

**fract-ol** is a program that generates beautiful and complex fractals using mathematical formulas and displays them in a graphical window. The project combines **mathematics**, **graphics programming**, and **user interaction**.

The main goals include:

* Rendering fractals efficiently
* Understanding complex numbers
* Working with pixel-based graphics
* Implementing interactive controls (zoom, pan, etc.)

The project typically uses the **MiniLibX** graphics library provided by 42.

By completing this project, you will gain experience with:

## 🌐 Supported Fractals

### 🔹 Mandelbrot Set

* Most common fractal
* Generated by iterating complex numbers
* Displays a characteristic “infinite” boundary

---

### 🔹 Julia Set

* Similar to Mandelbrot but depends on a constant
* Produces a wide variety of patterns
* Often interactive (mouse-controlled parameters)

---

### 🔹 Adittional features (Optional)

* Gradienting coloring

## 🧩 How It Works

The program follows this general process:

1. **Map pixels to the complex plane**
2. **Apply iterative formula**

   * Typically:

     ```text
     z = z² + c
     ```
3. **Determine divergence**

   * If `|z|` exceeds a threshold → point escapes
4. **Assign color based on iterations**
5. **Render pixel to screen**

Each pixel represents a complex number, and its color reflects how quickly it diverges.
